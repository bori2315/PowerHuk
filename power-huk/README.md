# Power Huk (Right Huk Remastered)

Windows 11 스타일의 자체 호스팅 웹 앱 포털입니다. 일반 방문자는 로그인 없이 사이트를 이용하고, 관리자는 오른쪽 아래 캐릭터 버튼으로 별도 로그인합니다.

## 이번 버전의 기능
- 일반 방문자 즉시 입장 / 관리자 전용 로그인
- 자유게시판 게시글 작성 및 작성한 세션 기준 삭제
- 자유게시판 안의 **앱 요청 탭**: 방문자가 필요한 앱을 이름과 설명으로 제안
- 관리자가 앱 요청을 승인하거나 반려
- 승인할 때 관리자가 HTML 파일, 대표 사진(선택), 카테고리, 앱 주소를 지정해 앱으로 게시
- 앱 등록 시 카테고리 지정 및 관리자 카테고리 추가
- 앱 라이브러리의 카테고리 필터
- 앱 카드와 상세 오버레이의 대표 사진 표시
- 앱 카드를 누르면 제목·설명·카테고리·주소가 있는 상세 오버레이 표시
- 상세 오버레이에서 `열기`를 눌러 `/calculator` 같은 앱별 전체 페이지 주소로 이동
- 앱 삭제 시 HTML과 대표 사진 파일도 함께 삭제
- 관리자 전용 공지사항 작성
- JSON 기반 데이터 저장 (`data/db.json`)

## 실행 방법
1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 터미널을 엽니다.
3. 의존성을 설치합니다.
   ```bash
   npm install
   ```
4. `.env.example`을 복사해 `.env`로 만듭니다.
   ```bash
   cp .env.example .env
   ```
   Windows PowerShell에서는 `Copy-Item .env.example .env`를 사용합니다.
5. `.env`의 `SESSION_SECRET`과 관리자 비밀번호를 확인합니다.
6. 실행합니다.
   ```bash
   npm start
   ```
7. 브라우저에서 `http://localhost:3000`에 접속합니다.

## 관리자 로그인
- 아이디: `admin`
- 기본 비밀번호: `123`

요청에 따라 기본값은 `123`입니다. 공개 인터넷에 배포하기 전에는 반드시 강력한 비밀번호로 바꾸고 `SESSION_SECRET`도 길고 임의적인 문자열로 변경하세요. 기존 `data/db.json`이 있어도 `.env` 값으로 로그인하면 관리자 인증 정보가 동기화됩니다.

## 앱 등록 및 앱 요청 승인
- 관리자 센터의 HTML 앱 등록에서 앱 이름, 설명, 주소, 카테고리, HTML 파일, 대표 사진을 설정할 수 있습니다.
- HTML은 최대 2MB, 대표 사진은 최대 4MB이며 사진 형식은 PNG/JPG/WEBP/GIF입니다.
- 카테고리는 관리자 센터에서 추가할 수 있습니다.
- 방문자는 자유게시판의 앱 요청 탭에서 앱을 제안할 수 있습니다.
- 관리자는 관리자 센터의 앱 요청 검토에서 요청을 승인하거나 반려할 수 있습니다. 승인할 때 실제 실행할 HTML 파일과 카테고리를 선택해야 앱이 게시됩니다.
- 승인된 앱은 요청 제목으로 등록되고 `/요청한-앱-주소`에서 실행됩니다. 주소 입력을 비워 두면 이름에서 자동 생성하며, 한글 이름은 임의의 `app-xxxxxx` 주소가 될 수 있습니다.

## 앱 실행 보안
- 업로드된 HTML 앱은 sandbox iframe 안에서 실행되며 Power Huk의 세션 쿠키와 API에 접근할 수 없습니다.
- HTML 파일은 실행 가능한 코드입니다. 관리자에게만 업로드 권한을 주고, 업로드 전 파일 내용을 검토하세요.
- 업로드 사진은 PNG/JPG/WEBP/GIF만 허용하며 SVG는 받지 않습니다.
- 인터넷 공개 배포 시 HTTPS, 강력한 관리자 비밀번호, 백업, 서버 업데이트를 적용하세요.

## 기존 데이터 유지
기존 버전을 업데이트할 때 `data/`와 `uploads/` 폴더는 새 프로젝트에 덮어쓰지 말고 보존하세요. 새 버전은 기존 `db.json`을 읽을 때 앱 카테고리와 앱 요청용 데이터 필드를 자동으로 추가합니다. 기존 앱은 `기타` 카테고리로 표시됩니다.

## 데이터 백업
서버를 종료한 뒤 `data/db.json`과 `uploads/` 폴더를 함께 백업하면 게시글, 앱 요청, 앱 HTML, 대표 사진을 보존할 수 있습니다.
